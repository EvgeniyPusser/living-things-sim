## 1. Три слова, закреплённые за измеримым

```
особь      то, что ведёт ОДИН непрерывный архив и имеет ОДНУ точку решения
           граница — докуда достаёт её сеть
           кончается, когда архив брошен или разделён

тело       стены, мощность, граф как-построено. НЕ наследуется,
           берётся с участка и из проекта

ген        правило, которое ДЕЙСТВУЕТ: расписание, порог, порядок мер
           три проверки:
             1) читается особью с другим телом
             2) действует само, без остального донора
             3) можно померить, что было с ним и без него

запись     что случилось. Наблюдение. Само по себе не действует.
           Из многих записей выводится ген; запись наверх не передаётся,
           она слишком привязана к телу
```

Фенотип — поведение, не стены. Стены это среда, в которой ген читается.

**Измеренная наследуемость, первое настоящее число под этим словом:**

```
тело получателя   67 %
ген (чей он)      26 %
их сочетание       6 %
```

Отсюда же ответ, почему ДНК не несёт фенотип: три четверти решает то,
чего в геноме нет.

## 2. Представление: граф, а не вложенный массив

```
дерево    адрес и владение:  city-04 / house-12 / wall-3 / sect-2
рёбра     что с чем связано: несёт, питает, электрически связан,
                              делит общий ресурс
```

Вложенность даёт адрес. Связи режут её поперёк: контур отопления идёт через
плиту и стены, сеть арматуры охватывает три стены, электросеть связывает дома
из разных кварталов.

**Техническое, которое потом дорого стоит:** не хранить вложенным JSON-ом.
Плоская таблица узлов с путём-строкой плюс таблица рёбер с типом. Иначе запрос
«все стены такого-то года по всем домам» — обход всего дерева.

**Школа, с которой говорить:** Уорден, Булл, Дервилис — приписанные графы,
irreducible element models, наибольший общий подграф для решения о допустимости
переноса. Это редакторы того спецвыпуска Data-Centric Engineering.

**Развитие = переписывание графа.** Графовые грамматики, L-системы. То есть
«эмбриология живых вещей» не тёмная область: состояние это граф, развитие это
правила переписывания. Одна математика, а не две.

**Оговорка:** расстояние редактирования и наибольший общий подграф — NP-трудные.
На городе не считается. Нужны ядра или приближения, заложить сразу.

## 3. Четыре режима развития — там, где кончается индивид

```
собранные     дом, самолёт, станок
              есть рождение, есть граница, есть первый цикл под нагрузкой

выращенные    завод, трубопроводная сеть, дорога
              рождения нет, есть прибавление; индивид — сама сеть

заселённые    город, жилой фонд, интернет
              плана нет; развитие это отбор среди пришедшего

грибничные    экосфера живых вещей, сама библиотека Cloud DNA
              ни границы, ни центра, ни поколения
```

Cloud DNA относится к четвёртому типу. Если рамка верна, она обязана
применяться к себе самой.

**Величины для грибничного уровня** (у нас нет ни одной):

```
доля частей, ведущих записи
сколько живёт запись, прежде чем её перестают читать
через сколько чужих объектов она проходит
сколько версий держится одновременно
```

**Честно сказать в статье:** рамка предлагается для четырёх режимов, проверена
на одном — самом лёгком, где есть граница, зима и счёт.

## 4. Переход на уровень выше: пять родов правил

```
складывающиеся   энергия, площадь          сумма
интенсивные      температура, U            среднее с весами
хвостовые        риск, отказ, дефицит      квантиль или счёт превышений
связанные        всё синхронное            сумма + член ρ
неагрегируемые   какая стена треснула      наверх не идёт вообще
```

Пятую строку заполнять честно: рамка, говорящая, что умирает при каждом
подъёме, серьёзнее рамки, где всё сохраняется.

**Цена меняется с уровнем, физика — нет.** Одно событие, 72 часа мороза:

```
жильцу    градусо-часы и счёт
сети      пик мощности, не сумма за сезон
городу    сколько домохозяйств ушло ниже порога
стране    сколько районов одновременно
```

Цена — объявленный выбор того, кто платит, а не истина. В записи должна стоять
рядом с числом.

**Требование композиции и где оно ломается.** Подняться на два уровня разом
обязано равняться подняться дважды. Для суммы и взвешенного среднего верно.
Для квантилей — нет: медиана медиан не равна медиане. Следствие жёсткое:
**хвостовые величины едут наверх распределением, а не сводкой.** То же с ρ:
её нельзя усреднить по кварталам, пересчитывать на том уровне, где вопрос.

## 5. Утверждение, которое можно опровергать

> Наследование, оптимальное для отдельной вещи, тем опаснее для населения,
> чем выше согласованность источников. Мера опасности — член связанности:
> разброс агрегата растёт как N, а не как корень из N.

Арифметика:

```
независимые   дисперсия суммы = N·σ²
связанные ρ   дисперсия суммы = N·σ² + N(N−1)·ρ·σ²

ρ = 0     тысяча домов, размах ≈ 31·σ
ρ = 0.94  тысяча домов, размах ≈ 970·σ      в 31 раз больше
```

0.94 — наше измеренное, из опыта 13.

**Что здесь наше, а что известно:**

```
дисперсия суммы связанных величин   элементарная статистика
квантили не складываются            известный факт
огрубление графов                   стандартная математика
цена меняется с уровнем             близко к многокритериальным и
                                    многомасштабным работам — ПРОВЕРИТЬ
```

Новое — сборка плюс подставленное измеренное ρ из настоящего опыта по переносу.
**Прежде чем заявлять, искать в трёх местах:** коллективное поведение
популяций зданий и demand response, многомасштабное моделирование, разнообразие
политик в обучении с подкреплением.

## 6. Инфраструктура: общий ресурс, а не узел и не сумма

Своё состояние, одно на всех: частота, давление, напряжение, занятость.
Две РАЗНЫЕ карты:

```
вклад            participation factor   сколько каждый добавляет
подверженность   sensitivity coefficient сколько каждый чувствует
```

Они не совпадают. Дом в конце фидера берёт мало, просадку получает
наибольшую. Крупный потребитель у подстанции даёт главный вклад и почти
ничего не чувствует.

**Асимметрия вклада и подверженности — это и есть место, где живёт
конституционная допустимость из 6.6.** Пока не записана — слова. Записана —
матрица, и её считают (матрица чувствительности).

**Имя брать: common-pool resource.** За ним Элинор Остром, нобелевская премия
2009. Её свод принципов — кто берёт, кто следит, кто разрешает споры, кто
меняет сами правила — это ваша Конституция, написанная за сорок лет до нас на
рыболовных угодьях и оросительных каналах. Главный её вывод: устойчивые общие
ресурсы держатся правилами, которые устанавливают и меняют сами участники.

**Слово «поле» не брать** — спросят уравнение поля, а его нет.

**Постоянна только на быстром времени.** На медленном инфраструктура
изнашивается и прирастает, то есть сама живая вещь выращенного типа.

**В запись добавить положение в среде:** к какому узлу присоединён, какой
вклад даёт, какую подверженность имеет. Без этого унаследованное правило
поедет: расписание, выученное у подстанции, в конце фидера сработает иначе —
не потому что дом другой, а потому что место другое.

**Ограничение нашей напечатанной статьи, которое в ней не названо:** все дома
висели в пустоте, без сети. Если возьмут в рецензию — один из трёх вопросов,
которые зададут.

## 7. Вторая линия наследования: ниша

**Niche construction** — Оделинг-Сми, Лаланд, Фельдман. Организм меняет среду,
изменённая среда меняет отбор на него и на потомков. **Ecological inheritance** —
их же термин.

```
первая линия   ген: правило переходит от особи к особи
вторая линия   ниша: среда изменена и достаётся следующим как данность
```

Вторая работает там, где библиотеки нет вовсе. Город наследует сам себе,
ничего не записывая.

**Петля.** Все дома унаследовали почти одно расписание (ρ = 0.94) → одинаково
нагружают сеть → сеть усиливают под это поведение → следующее поколение
рождается в сети, приспособленной под общее расписание, и снова его выбирает.
Согласованность сама себя укрепляет. Разнообразие не просто теряется — оно
дорожает, потому что среда его больше не поддерживает.

В Части II второй линии нет. В 6.7 эволюция идёт по генам при неподвижной
среде, чего в природе не бывает.

## 11. Зачаток: система возникновения, создаваемая до вещи

Добавлено 29 сентября.

**Мысль.** Сегодня порядок такой: спроектировали, построили, потом прикрутили
управление, регламент обслуживания и аварийный план — разные люди, в разное
время, разными документами. Предлагается перевернуть: **сначала создаётся
система того, как вещь возникает, растёт, чинится, работает и ведёт себя в
беде.** Вещь — то, что эта система производит.

**Что отличает зачаток от проектной папки.** Папку нельзя запустить. Зачаток
можно: дать ему участок и запись погоды — он выдаёт предсказанный фенотип до
первого кирпича. **Зачаток — документ, который исполняется против участка.**

**Имя.** Не «яйцеклетка»: клеточное слово рядом с утверждением о неклеточности.
Точный термин — **propagule**, пропагула: единица размножения, клеткой быть не
обязана (споры, отводки, куски мицелия). По-русски «зачаток».

**Семь разделов, одинаковых для всех классов:**

```
1  возникновение    что считается первым моментом
2  функционирование контур обычной работы
3  экстренное       лестница мер с порогами, от дешёвых к дорогим
4  регенерация      что чинится на месте, какой ценой, сколько раз
5  рост             как меняется тело за жизнь
6  предел           когда обязана остановиться и что станет с записями
7  провал           где этот зачаток не работает
```

Шестой обычно забывают. У самолёта и реактора он обязателен: назначенный
ресурс, число циклов, детали с ограниченным сроком. У дома его нет.

**По классам:**

```
                рождение              рост      починка на месте   экстренное
дом             первая зима           редко     почти нет          нет ничего
машина          первый цикл нагрузки  нет       узлами             частично
самолёт         первый полёт          нет       в полёте почти нет полная лестница
корабль         ходовые испытания     редко     ДА, главный случай полная
электростанция  синхронизация с сетью нет       резервными нитками эшелонирована
завод           первый полный выпуск  постоянно да                 частично
город           нет                   всегда    заменой частей     нет
```

**ГЛАВНОЕ, и это надо сказать прямо, иначе разнесут.** В авиации и атомной
энергетике зачаток существует шестьдесят лет, только называется иначе:

```
сертификат типа                 возникновение
программа обслуживания, MSG-3   регенерация
QRH, карты действий             экстренное — буквально лестница с порогами
перечень деталей с ресурсом     предел
глубоко эшелонированная защита  та же лестница у реактора
```

Отсюда: **для самолёта новизна не в зачатке, а в том, чтобы сделать его
исполняемым и наследуемым по парку.** Сейчас QRH — бумага, и опыт одного борта
попадает в общий фонд через людей и годы. **Для дома новизна в самом зачатке:
его нет вообще.** Смешивать эти два случая нельзя — рецензент из авиации
скажет «вы описали Type Certificate Data Sheet», и будет прав.

**Где форма ломается — город.** Ни рождения, ни границы, ни единого автора, ни
предела. Зачатка у города быть не может. Но: **зачаток города — это его
строительные нормы.** Правила, по которым возникают его части. Город не имеет
механизма собственного возникновения, он имеет механизм возникновения того, из
чего состоит.

```
дом    имеет свой зачаток
завод  имеет свой и задаёт зачатки своих линий
город  своего не имеет, задаёт зачатки домов
```

Зачаток на одном уровне — норма для уровня ниже.

**Что измеримо на всех классах разом.** Есть ли у вещи лестница экстренных мер
с порогами и ценами, или одна ступень. У самолёта есть, у реактора есть, у дома
нет. Гипотеза: лестница дороже в обычной жизни и окупается в редком событии —
ровно то, что намеряно на тепле: 42 % пользы в 1.4 % сезона. Переносится на
любой класс без новой физики, мера одна — сколько платишь всегда, сколько
спасаешь редко.

**Поправки к «яйцеклетке» из разговора с ChatGPT:**

```
индивидуальность в облаке   НЕТ. Особь ведёт архив и решает; облачная запись
                            не прожила ничего. В облаке заводится МЕСТО В
                            РОДОСЛОВНОЙ, а не особь
семя восстановления         НЕТ. Чип плюс разрушенный дом не дают дом: нужны
                            материалы, участок, люди, деньги. Чип держит
                            правила, записи и тождество. Это завещание,
                            а не семя
неклеточность               следствие, которого не было: НЕТ ВОССТАНОВЛЕНИЯ
                            ИЗ ЧАСТИ. Биология чинится на месте, потому что
                            в каждой клетке весь геном И средства рядом.
                            Чипы возвращают информационную избыточность,
                            не строительную. Сколько ремонтов осталось
                            в стене — это и есть, сколько у неё клеточности
```

**Критерий, что в облаке, а что местно:**

```
местно    всё, что обязано сработать при оборванной связи и быстрее,
          чем связь может гарантировать
в облаке  всё остальное; обязательно всё, что наследуется между особями,
          потому что наследование происходит МЕЖДУ, а не внутри
```

## 12. Место математики (по записке «Living Things: математика как внутренний язык Cloud DNA»)

Размещение верное: математика внутри Cloud DNA, а не в основании всей
концепции. Четыре добавления.

**Ловушка «формализовать там, где нужно».** Тогда нельзя отличить свойство
системы от свойства своего выбора. Наш случай: пять чисел дали ρ = 0.94, и
честный ответ появился только после переописания двадцатью шестью. Правило:
формализовать там, где нужно, **и всегда проверять, что результат переживает
другую формализацию.**

**Формат определяется исключениями.** Сказано, что Cloud DNA хранит; не сказано,
чего не хранит. Завести раздел «что не сохраняется при подъёме»: записи наверх
не идут, неагрегируемое умирает, квантиль едет распределением.

**Цена — не математика.** Она объявляется тем, кто платит, и меняется с уровнем.
Хранить как решение с хозяином: кто назначил, когда, на каком основании, на
каком уровне действует. Это конституционный объект, а не настройка.

**Довод про биомиметику завершить.** Принцип переносится без математики.
**Границы принципа без математики не устанавливаются.** Математика нужна не
чтобы описать процесс, а чтобы очертить, где он ещё верен.

**Мелочь:** в §4 той записки формула вытекла как `N\sigma^2 + N(N-1)\rho\sigma^2`
со скобкой. Словами: дисперсия суммы равна N·σ² плюс N(N−1)·ρ·σ².
