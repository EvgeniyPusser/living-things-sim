# Ссылки на живые страницы

Обе страницы считают модель прямо в браузере, сеть им не нужна.
Файлы лежат рядом: `bench.html` (англ.) и `stend.html` (рус.).

```
английская   https://claude.ai/artifact/Cj9CWyNwrLzaP1f6fFCXPM
русская      https://claude.ai/artifact/ERX819Apkn7dDoZRD6geXd
```

## Пока они приватные

По ссылке откроются только у вас. Чтобы открывались у других:
открыть страницу, нажать **Share**, разрешить доступ по ссылке.
Это делается один раз и только вами.

## Что надёжнее для встречи

Файл с диска. Он не зависит от сети и от того, вошли ли вы в аккаунт
на чужом компьютере. Ссылку давайте после встречи, чтобы человек
мог вернуться.

## Если правили текст на странице

`stend.html` собирается из `build.py`.
`bench.html` получается из `stend.html` через `translate.py` —
там простая таблица замен, правится руками.
