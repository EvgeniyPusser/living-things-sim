## Три дефекта, найденные 23.09

**1. Самообучение в life.py не работает.**
Дом раз в неделю пробует изменить расписание и по журналу решает, оставить или нет.
За год из ~40 проб принимаются 2–3, и итог хуже начала.

```
самообучение против нетронутого расписания   медиана −0.2%, помогло 13% домов
```

Это не надо чинить. Это результат: настоящее здание тоже само не учится.
Но значит, что условие «одна» во всех опытах — это нетронутое расписание,
а не самообучающийся дом. Формулировку «дом легко учится сам» надо убрать отовсюду.

**2. Шаг в один час слишком крупный.** (life.py, life2.py)
`gain` прибит к единице, котёл всегда на полную. Дому нужно 3 градуса,
котёл за час даёт 6.3. Температура скачет:

```
18.0 → 24.31 → 18.22 → 24.48 → 18.35 → 24.58
```

Дом никогда не держит 21. Сравнения условий между собой скорее всего уцелеют —
качели одинаковые везде. Абсолютные цены завышены.
Чинить: 6 шагов по 10 минут вместо одного часового.  **НЕ СДЕЛАНО.**

**3. Планка комфорта ездила.** (только sim.py, то есть только опыт 1)

```python
if occ[i] and T < T_occ - band:      # T_occ дом подбирает сам
```

Дом опускал `T_occ` с 21 до 18 и тем снижал планку штрафа с 20.5 до 16.
То есть «учился» наполовину тем, что переставлял линейку.
Исправлено в `sim_fixed.py`, пересчитано.

```
                       БЫЛО              СТАЛО
чужое как есть    −10.4%, помог 28%   −11.9%, помог 26%
чужое + подстройка +4.8%, помог 81%    +3.8%, помог 81%
связь с различием тел  +0.21              +0.05
```

Вывод опыта 1 устоял: чужая настройка целиком вредит, как начальная точка помогает.
Одно изменилось по существу: связь с различием тел упала с +0.21 до +0.05,
то есть исчезла совсем. Раньше можно было подумать, что похожесть домов
что-то значит. Теперь — нет, и это сходится со всеми остальными опытами.
