# living-things-sim

Перенос выученного управления между домами.

Вопрос: сколько стоит чужой опыт и при каком различии домов он перестаёт помогать.

## Что здесь

```
sim.py      дом (10 свойств), погода, тепловой баланс, цена, обучение,
            расстояние между домами. Контроллер из 5 чисел.
run.py      опыт 1: 10 домов, все пары переносов.      python run.py 7
sim24.py    контроллер из 24 чисел: уставка на каждый час суток
run24.py    опыт 2: короткая жизнь новичка.            python run24.py 7
```

Число в команде — зерно случайности. Посчитаны 7, 8 и 9.

Результаты лежат в `transfer_seed*.csv` и `transfer24_seed*.csv`:
по строке на каждый перенос, колонки `donor`, `receiver`, `distance`,
`scratch`, `as_is`, `tuned`.

## Что нужно

```
pip install numpy pandas scikit-learn
```

`scikit-learn` — только для разбора выбора донора.

## Три условия переноса

```
scratch   дом учится с нуля от типовой настройки, короткий бюджет
as_is     берёт контроллер донора как есть, ноль попыток
tuned     берёт контроллер донора как начальную точку, тот же короткий бюджет
```

Выигрыш считается против `scratch`, в процентах. Положительный — перенос помог.

## Что получилось (270 переносов на опыт)

```
                            опыт 1        опыт 2
as_is, в среднем            −10.4 %       −3.6 %
as_is хуже обучения с нуля     72 %          48 %
tuned, в среднем             +4.8 %       +0.5 %
связь с расстоянием          +0.21        около нуля
```

Вывод: в этой модели наследование почти не имеет цены, потому что выучить
своё слишком легко. Опыт стоит ровно столько, сколько стоит добыть его заново.

## Важное

Данные синтетические. Физика упрощённая: одна зона, без влажности, без соседей.
Границы свойств домов, цена киловатт-часа и вес комфорта выбраны автором.
Это утверждения о модели, а не о настоящих зданиях.
